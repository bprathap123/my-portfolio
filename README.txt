PRATHAP'S PORTFOLIO — QUICK START

FILES
- index.html: website content
- style.css: colors and layout
- script.js: mobile menu and current year

STEP 1: OPEN LOCALLY
1. Extract this folder to your Desktop.
2. Open VS Code.
3. Choose File > Open Folder > select my-portfolio.
4. Open index.html.
5. If you have Live Server installed, right-click index.html > Open with Live Server.
   Otherwise, double-click index.html in File Explorer to preview it.

STEP 2: PERSONALIZE BEFORE PUBLISHING
Open index.html and replace:
- YOUR_EMAIL@example.com with your professional email
- GitHub link https://github.com/ with your actual profile
- LinkedIn link https://www.linkedin.com/ with your actual profile
- Any project descriptions that don't accurately describe completed work
- The displayed name/education details if needed

STEP 3: PUBLISH FOR FREE WITH GITHUB PAGES
1. Sign in at https://github.com/ or create an account.
2. Create a NEW PUBLIC repository named my-portfolio.
3. In the repository, click Add file > Upload files.
4. Upload index.html, style.css, script.js, and README.txt from this folder.
   Upload the files themselves into the repository root, not an extra nested folder.
5. Click Commit changes.
6. Go to repository Settings > Pages.
7. Under Build and deployment, select Deploy from a branch.
8. Choose branch main and folder /(root), then click Save.
9. Wait a few minutes and refresh the Pages section to find the published URL.
   It will look like https://YOUR-GITHUB-USERNAME.github.io/my-portfolio/

IMPORTANT
- The URL is not live until you complete the GitHub Pages steps.
- Do not publish private information such as your home address, passwords, or ID numbers.
- This portfolio is a static website; it does not require a database or backend.
